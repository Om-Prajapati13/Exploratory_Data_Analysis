# Exploratory Data Analysis of Titanic Dataset

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Setup Instructions
1. Ensure you have Python, Pandas, Matplotlib, and Seaborn installed.
2. Place the 'Titanic-Dataset.csv' dataset in the same directory as the script.
3. Run the Jupyter Notebook to generate visualizations and identify patterns.
